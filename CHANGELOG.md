# Changelog

## 0.1.0 — 2026-10-19

First public version.

- English and Russian messages, buttons, help and documentation.
- Secure interactive setup with detected SSH ports and an explicit timezone.
- Fail2ban notifications, per-IP controls and confirmed `/24` operations.
- Persistent whitelist, local ban history, audit log and disk-backed outbox.
- An installer with preflight checks, owned-file backups and rollback.
- Opt-in geolocation with documented data destinations.
- Reproducible synthetic demo screenshots, unit tests and isolated Linux CI.
- Publication checks for credentials, runtime artifacts and non-demo IPv4 addresses.
